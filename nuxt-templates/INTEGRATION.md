# Nuxt.js Blog Integration Guide

How to integrate the blog templates into your Custyle Nuxt.js website.

## Prerequisites

- Nuxt 3.x project
- Node.js ≥ 18

## 1. Install Dependencies

```bash
npm install @nuxt/content @nuxt/image @nuxtjs/sitemap
```

## 2. Configure nuxt.config.ts

```ts
export default defineNuxtConfig({
  modules: [
    '@nuxt/content',
    '@nuxt/image',
    '@nuxtjs/sitemap',
  ],

  content: {
    // Blog content lives in content/blog/
    documentDriven: false,
    highlight: {
      theme: 'github-dark',
    },
  },

  site: {
    url: 'https://custyle.ai',
  },

  sitemap: {
    sources: ['/api/__sitemap__/urls'],
  },

  image: {
    quality: 80,
    format: ['webp', 'avif'],
  },
})
```

## 3. Copy Page Templates

Copy the following files into your Nuxt project:

```
nuxt-templates/pages/blog/index.vue       →  pages/blog/index.vue
nuxt-templates/pages/blog/[slug].vue      →  pages/blog/[slug].vue
nuxt-templates/pages/blog/category/[slug].vue → pages/blog/category/[slug].vue
nuxt-templates/components/BlogCard.vue     →  components/BlogCard.vue
```

## 4. Create Content Directory

```bash
mkdir -p content/blog
```

## 5. Add Blog Articles

Place Markdown files (generated by Auto_Skill) in `content/blog/`:

```
content/blog/
├── what-is-agentic-commerce-guide-2026.md
├── what-is-ai-merch-agent.md
├── prompt-to-product-guide.md
└── ...
```

Each file must have YAML frontmatter:

```yaml
---
title: "Article Title"
description: "Meta description (150-160 chars)"
summary: "Card display summary"
author: custyle-team
date: 2026-02-07
category: agentic-commerce
tags: [agentic-commerce, AI]
cover: "/images/blog/cover.jpg"
coverAlt: "Alt text"
readingTime: "8 min"
draft: false
seo:
  primaryKeyword: "primary keyword"
  secondaryKeywords: ["keyword 2", "keyword 3"]
---
```

## 6. Add Navigation Entry

Add a Blog link to your site navigation:

```vue
<NuxtLink to="/blog">Blog</NuxtLink>
```

Also add to the footer:

```vue
<NuxtLink to="/blog">Blog</NuxtLink>
```

## 7. Homepage Blog Section (Optional)

Add a "Latest from the Blog" section to your homepage:

```vue
<template>
  <section class="home-blog">
    <div class="container">
      <h2>Latest from the Blog</h2>
      <div class="home-blog__grid">
        <BlogCard
          v-for="article in latestArticles"
          :key="article._path"
          :article="article"
        />
      </div>
      <NuxtLink to="/blog" class="home-blog__link">
        View All Articles →
      </NuxtLink>
    </div>
  </section>
</template>

<script setup>
const { data: latestArticles } = await useAsyncData('home-blog', () =>
  queryContent('/blog')
    .where({ draft: { $ne: true } })
    .sort({ date: -1 })
    .limit(3)
    .find()
);
</script>
```

## 8. RSS Feed (Optional)

Create `server/routes/rss.xml.ts`:

```ts
import { serverQueryContent } from '#content/server';
import { Feed } from 'feed';

export default defineEventHandler(async (event) => {
  const articles = await serverQueryContent(event, '/blog')
    .where({ draft: { $ne: true } })
    .sort({ date: -1 })
    .limit(20)
    .find();

  const feed = new Feed({
    title: 'Custyle Blog',
    description: 'Insights on Agentic Commerce and AI Merchandising',
    id: 'https://custyle.ai/blog',
    link: 'https://custyle.ai/blog',
    language: 'en',
    copyright: `Copyright ${new Date().getFullYear()} Custyle`,
  });

  for (const article of articles) {
    feed.addItem({
      title: article.title || '',
      id: `https://custyle.ai${article._path}`,
      link: `https://custyle.ai${article._path}`,
      description: article.description || '',
      date: new Date(article.date),
    });
  }

  event.node.res.setHeader('Content-Type', 'application/xml');
  return feed.rss2();
});
```

Install the `feed` package: `npm install feed`

## 9. Auto-Deploy Workflow

Set up the Auto_Skill → Nuxt deployment:

1. In Auto_Skill `.env`, set:
   ```
   BLOG_CONTENT_DIR=/path/to/custyle-website/content/blog
   ```

2. Generate and publish:
   ```bash
   cd /path/to/Auto_Skill
   npm run generate
   npm run validate
   npm run publish -- --deploy
   ```

3. The article will be copied to your Nuxt project's content directory.

4. Commit and deploy your Nuxt project.

## 10. SEO Checklist

After integration, verify:

- [ ] `sitemap.xml` includes `/blog` routes
- [ ] Each article page has correct `<title>`, `<meta name="description">`, and OpenGraph tags
- [ ] JSON-LD `BlogPosting` schema renders on article pages
- [ ] Breadcrumbs display correctly
- [ ] Canonical URLs are self-referencing
- [ ] RSS feed is accessible at `/rss.xml`
- [ ] Images have alt text and lazy loading
- [ ] Category pages have descriptive intro text (not thin content)
- [ ] Internal links work correctly between articles
